🎯 Hangman Game

A simple Hangman Game developed in Python, where the player tries to guess a hidden word one letter at a time. The game provides a limited number of incorrect attempts, making it a fun way to practice Python programming and logical thinking.

✨ Features

- 🎲 Random word selection
- 🔤 Letter-by-letter word guessing
- ❌ Tracks incorrect guesses
- ❤️ Displays remaining attempts
- 🏆 Displays win or lose messages
- ✅ Validates user input
- 💻 Simple command-line interface

🛠️ Technologies Used

- Python 3
- Google Colab / Jupyter Notebook

📚 Concepts Used

- Variables and Data Types
- Conditional Statements ("if", "elif", "else")
- Loops ("while", "for")
- Lists and Strings
- Functions
- Random Module
- User Input and Output

▶️ How to Run

1. Clone this repository or download the project.
2. Open the Python file or notebook using Google Colab or Jupyter Notebook.
3. Run all the cells in order.
4. Follow the on-screen instructions to play the game.
5. Enter one letter at a time to guess the hidden word.

🎮 Gameplay

Word: _ _ _ _ _

Guess a letter: a

Correct guess!

Word: _ a _ _ _

If the player makes too many incorrect guesses, the game ends and displays a Game Over message.

🎯 Objective

The objective of the game is to guess the hidden word before the maximum number of incorrect attempts is reached.
